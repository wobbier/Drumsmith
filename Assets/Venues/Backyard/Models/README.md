# Backyard Party models

The scene uses the game's existing [Town atlas](../../../Models/Venue/PolygonTown_01_A.png) through `Yard.mtl`. All dimensions are in metres. To rebuild from the repository root, run `python3 -B Tools/Venues/make_backyard.py`. The game’s tools build cooks an OBJ into its adjacent `.obj.assbin` the first time it loads. Distribute those twins with the venue in a retail package.

| Runtime geometry | Source and treatment |
| --- | --- |
| NeighbourHouse, PoolBasin, PoolWater, Trampoline, PartyConvertible, Sofa, PatioChair, Barbecue, PrivacyFence, FencePost, FloatRing, NoveltyFloat, FloatBed, DivingBoard, StreetLamp, GardenLantern, PatioTable, PottedPlant, GardenTree | Owner's Synty Polygon Town pack. [Per-model source, scale, removed geometry and hashes](../../../../Art/Venues/Backyard/Models/Imported/inventory.json). The runtime exporter preserves vertices, UVs and normals and consolidates draw groups onto the shared atlas. |
| PartyHouse, PatioDeck, DrumRiser, ProjectionSheet, PatioTV, PatrolLightbar | [Original architecture](../../../../Art/Venues/Backyard/Models/Architecture/generate_architecture.py). The runtime pass reassigns siding, trim and shutters to darker atlas swatches so the lit windows and paint read at night. |
| BounceHouse, Pergola, TikiTorch, OneMoreSongBanner, SearchlightHousing | [Original party props](../../../../Art/Venues/Backyard/Models/Original/generate_original_props.py). The fixed two-metre festoon from the study is replaced by continuous hand-rigged lines. |
| AftersDrop, GateFlyers, RadioShutter, DoorDecks, PatchworkFly, PaperCup, BeachTowel, PicnicRug, PatioMorning, PoolWakes, PracticalGlass | [Original runtime meshes](../../../../Tools/Venues/backyard_meshes.py), including the lettering and painted marks. PracticalGlass is one eight-sided mesh instanced for the bulbs and torch tips; per-instance materials provide emission. |
| RallyBall, PaperCrate | [Original meshes and the trampoline jumper's motion](../../../../Tools/Venues/backyard_drop.py). The six-panel beach ball floats in the pool as set dressing. The crates have open slats and bundled rolls of coloured paper. |
| GardenRigging | [Built with the layout](../../../../Tools/Venues/make_backyard.py): cables follow the same sag curves as the sockets. Pennants, ties, splices, props and leads are combined into one venue-space mesh. |
| Character meshes named `<look>_<piece>_<angle>` | Derived from the matching [game crowd piece](../../../Models/People/Crowd). The trailing number is the bend in degrees. The tailor edits vertices around the knee or elbow, recalculates normals and preserves UVs except for the seated guest's denim and shoes. Joint pivots are retained for the [seven original performances](../../../../Tools/Venues/backyard_guests.py). |

Most props use floor-centred pivots. GardenRigging, PatioMorning and PoolWakes preserve venue positions; the towel, rug, glass and character pieces use placement or joint pivots. Stock amps, wedges, instruments and other shared assets retain their [original provenance](../../../Models/Venue/README.md). The Synty source meshes, derivatives and atlas remain subject to their existing asset licence.
