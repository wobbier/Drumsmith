# StoryEventHorizon models

Every mesh here is original, generated by `Tools/Venues/make_story_event_horizon.py` (helpers
`Tools/Venues/story_event_horizon_*.py`); rerun it to rebuild. No Synty pack files are copied into
this folder.

- `EH_Palette.png` / `EH.mtl`: a drawn 16 x 16 swatch palette; the meshes pick a texel per face.
- `Hall.obj`, `RingPylons.obj`, `Ring1-5.obj`, `RingGlow1-5.obj`, `RingNodes1-5.obj`, `RingClamps.obj`,
  `ClampLamps.obj`: the rotunda and the five brass drive rings (glow parts are overridden with
  emissive materials in the scene).
- `Stars*.obj`, `PhotonRing.obj`, `Lens*.obj`, `Disc*.obj`, `LensedStars.obj`: the star field and the
  black hole (all emissive overrides).
- `MusicStand.obj`, `RehearsalLamp.obj`, `LampShade.obj`, `ConductorPodium.obj`, `Conductor_*.obj`,
  `KitLeads.obj`, `HatLoonie.obj`: stage props and the house conductor.
- `Plaque*.obj`, `Frieze*.obj` with `../Textures/*.png`: engraved plates drawn with ffmpeg drawtext
  (DejaVu Serif Bold); every inductee name is invented.

Shared props referenced in place (read-only) from `Assets/Models/Venue/`: `Wedge.obj`,
`GuitarCab.obj`, `AmpHead.obj`, `DrumRug.obj` (owner's Synty licence, see that folder's README).
