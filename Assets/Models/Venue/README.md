Geometry and UVs are retained; vertices are uniformly scaled to the stated real-world size in metres (Speaker 1 m, RoadCase 0.85 m tall) with a floor-centred pivot unless noted. Local MTL files bind the supplied atlases. No dependency on the test project at runtime.

`PolygonTown_Crowd.png` is generated, not sourced: `Game/Tools/MakeCrowdPieces.py` packs the twelve `PolygonTown_0N_L.png` character atlas variants into one 4 x 3 grid (8192 x 6144, each tile unchanged) for the crowd, which picks a tile per figure (`Docs/Venue-and-Band.md`, The figure). Rerun the tool after changing a variant.
